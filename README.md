# Setting up Claude for your own research workflow

This repo holds one file: [`claude-setup-guide.md`](claude-setup-guide.md).

It's not documentation to read on its own — it's meant to be **downloaded and handed to your own Claude** (Claude Code, or another Claude with file and shell access on your machine). Your Claude reads it, interviews you about your own research workflow, and helps you set up only the pieces that actually fit — not a copy of anyone else's setup.

It was written as a companion to a sociology graduate methods seminar on using AI tools in social science research.

## How to use it

1. Download `claude-setup-guide.md` (or clone this repo).
2. Open it in a Claude session that has file and terminal access on your machine (e.g. Claude Code).
3. Tell your Claude to read the file and follow its instructions.
4. Answer its questions honestly — it will not install, configure, or back up anything until you approve a plan.

## Prerequisite

You need Claude Code (or an equivalent Claude environment with file/shell access) already installed. This file can't install that part for you.
